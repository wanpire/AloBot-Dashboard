{# The component library. Every screen built from the Tabler shell is assembled from these macros, and no page template writes a framework class of its own: when Tabler's class names move, they move here and nowhere else. Two rules hold throughout. **Every macro forwards arbitrary attributes onto the element it renders.** Jinja calls cannot take `**{"hx-get": ...}`, so there are two doors: `attrs={"hx-get": "/x"}` for names that are not Python identifiers, and ordinary keywords whose underscores become dashes (`data_testid="row"` → `data-testid="row"`). Without this the macros could not host an hx-* or a data-testid, and every screen would have to break out of them. **Nothing here decides anything.** Macros format what they are handed. The one lookup table, STATE_TONES, is a colour and a default word per state - a presentation choice - and a test holds it against the model constants so it cannot fall behind them. Directions are logical throughout: ms/me, start/end, text-start/text-end. There is no `left` or `right` in this file, because the panel is RTL and a hardcoded side is a bug waiting for the first English label. #} {# ── Attribute plumbing ──────────────────────────────────────────────── #} {%- macro _attrs(extra, keywords, classes="") -%} {%- set merged = {} -%} {%- for key, value in (extra or {}).items() -%} {%- if merged.update({key: value}) -%}{%- endif -%} {%- endfor -%} {%- for key, value in (keywords or {}).items() -%} {%- if key not in ("class_", "caller") -%} {%- if merged.update({key | replace("_", "-"): value}) -%}{%- endif -%} {%- endif -%} {%- endfor -%} {%- set final_class = (classes ~ " " ~ (keywords.get("class_") or "")) | trim -%} {%- if final_class %} class="{{ final_class }}"{% endif -%} {{- merged | xmlattr -}} {%- endmacro -%} {# ── Icons ───────────────────────────────────────────────────────────── #} {# Inline SVG, one file per icon, only the ones actually used.
